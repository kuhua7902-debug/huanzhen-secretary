# 新机部署（快速清单）

> 这是**精简版**，适合已经部署过一次的人快速过流程。
> **第一次部署**请看完整的手把手版本 → [**《首次部署指南》**](首次部署指南.md)
> （含每一步的验收标准与「卡住了怎么办」）。

部署仓库：<https://github.com/kuhua7902-debug/huanzhen-secretary>

---

## 一、前置软件

| 软件 | 必须 | 说明 |
|---|---|---|
| Python **3.12**（64 位） | ✅ | 安装时勾选 **Add Python to PATH** |
| Git + Git LFS | 推荐 | 用 `git clone` 拉代码需要 |
| Node.js 18+ | 可选 | MCP 外部工具（文件/Excel/图表） |
| Ollama | 可选 | 知识库语义检索 |

## 二、获取项目

```powershell
git clone https://github.com/kuhua7902-debug/huanzhen-secretary.git
cd huanzhen-secretary
git lfs install
git lfs pull          # 拉取离线依赖包（约 400MB，只做一次）
```

> 不用 Git：仓库页 → Code → Download ZIP（不含 LFS 文件，将走联网安装）。

## 三、一键部署

双击 **`setup_deploy.bat`** —— 创建 `venv` 并安装依赖，约 3~8 分钟。

**成功标志**：提示部署完成，且出现 `venv\Scripts\python.exe`。

## 四、配置（两项必填）

双击 **`启动幻帧.bat`** —— 若缺 `.env` 会自动生成并打开记事本引导你填写。

手动方式：

```powershell
copy config.example.yaml config.yaml
copy .env.example .env
```

编辑 **`.env`**，至少改这两项：

```env
HUANZHEN_ADMIN_PASSWORD=你的强密码
DEEPSEEK_API_KEY=sk-xxxx
```

## 五、启动与验证

1. 双击 **`启动幻帧.bat`**（首次启动等 10~40 秒，就绪后自动开浏览器）
2. 双击 **`诊断.bat`** —— 期望「无阻断问题」
3. 浏览器 <http://127.0.0.1:8000/> → `admin` + 上面设的密码登录
4. 发一条测试消息，确认能正常回复

## 六、局域网给其他电脑用

服务已监听 `0.0.0.0:8000`，其他电脑访问 `http://<本机内网IP>:8000/`。

放行防火墙（管理员 PowerShell，执行一次）：

```powershell
New-NetFirewallRule -DisplayName "幻帧 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
```

## 七、日常操作

| 操作 | 方式 |
|---|---|
| 启动 | 双击 `启动幻帧.bat` |
| **停止** | 双击 **`停止服务.bat`**（或在 `运行服务.bat` 窗口按 `Ctrl+C`） |
| 自检 / 修复 | `诊断.bat` / `诊断.bat --fix` |
| 更新 | `git pull` → 重跑 `setup_deploy.bat` → 重启服务 |
| 看日志 | `logs\agent.log`、`logs\audit.jsonl` |

## 八、出问题

- 先双击 **`诊断.bat`**（会指出具体问题与修复命令）
- 再查 [**故障排查手册**](故障排查.md)（按症状组织）
- 完整部署流程见 [**首次部署指南**](首次部署指南.md)
