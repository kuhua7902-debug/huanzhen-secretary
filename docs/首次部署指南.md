# 首次部署指南（从零到能用）

> **适用**：第一次在一台 Windows 电脑上部署幻帧，从「拿到代码」到「能正常对话」的完整流程。
> **预计耗时**：20~40 分钟（其中离线依赖解包 ~5 分钟、首次启动 ~1 分钟）。
> **读完你会得到**：一个本机可访问、可局域网共享的 AI 助手。

本文每一步都带 **✅ 验收标准** 和 **⛔ 卡住了怎么办**。照着做，出问题也能自己定位。

---

## 〇、先确认你的电脑满足条件

| 项目 | 要求 | 必须 | 说明 |
|---|---|---|---|
| 操作系统 | Windows 10 / 11（64 位） | ✅ | 桌面自动化、语音等能力仅 Windows 可用 |
| Python | **3.12（64 位）** | ✅ | 仓库自带离线依赖是按 3.12 构建的；装其他版本需联网安装 |
| 磁盘空间 | ≥ 10 GB 可用 | ✅ | 依赖包约 2 GB，向量库/日志会持续增长 |
| 内存 | ≥ 8 GB | ✅ | 运行本体约 1~2 GB |
| [Git](https://git-scm.com/) + [Git LFS](https://git-lfs.github.com/) | 最新版 | 推荐 | 用方式 A 拉代码时需要；用方式 B 可跳过 |
| [Node.js](https://nodejs.org/) | 18+ | 可选 | 装了对的 MCP 外部工具（文件/Excel/图表）才完整 |
| [Ollama](https://ollama.com) | 最新版 | 可选 | 知识库语义检索需要它 |

> **不想装 Python？** 目前仍需要。打包成单个 exe 的路线见 `build.bat`，但尚未作为正式分发方式。

## 一、拿到代码

### 方式 A：用 Git 克隆（推荐，方便以后更新）

```powershell
git clone https://github.com/kuhua7902-debug/huanzhen-secretary.git
cd huanzhen-secretary

git lfs install
git lfs pull        # 下载离线依赖包（约 400MB，只做一次）
```

- `git lfs pull` 会拉取 `offline_packages/`（离线 wheel），**这是内网/无网环境能装上的关键**。
- 国内访问 GitHub 较慢时，可给 git 配代理：
  ```powershell
  git config --global http.proxy  http://127.0.0.1:7890
  git config --global https.proxy http://127.0.0.1:7890
  # 用完想取消：git config --global --unset http.proxy
  ```

### 方式 B：下载 ZIP（不用 Git）

1. 打开仓库页 → 绿色 **Code** 按钮 → **Download ZIP**
2. 解压到**不含中文和空格的路径**更好，例如 `D:\huanzhen`（含中文也能跑，但个别工具对路径敏感）
3. ⚠️ ZIP 下载**不含 LFS 文件**（`offline_packages/`），部署时会**自动联网安装依赖**

**✅ 验收**：项目根目录能看到 `setup_deploy.bat`、`main.py`、`requirements.txt`。

**⛔ 卡住了**
- `git: command not found` → 装 Git 后**重开**一个 PowerShell 窗口
- `git lfs pull` 报错 → 单独装 [Git LFS](https://git-lfs.github.com/)；或直接跳过走联网安装

## 二、一键安装

双击 **`安装.bat`**（推荐）。

它会依次完成：检查 Python / Git → 安装依赖 → **跑一次环境自检** → 生成桌面快捷方式 →
告诉你下一步该填什么配置。装完直接跳到第三步即可。

> 首次执行约 **3~8 分钟**（解包 + 安装 torch/chromadb 等大包），请耐心等待，**不要关窗口**。

### 如果只想装依赖（不想建快捷方式）

双击 **`setup_deploy.bat`**（等价于 `一键部署.bat`），它只做：创建 `venv/`、
优先用 `offline_packages/` 离线 wheel 安装依赖（没有则联网）、复制 `config.yaml`、创建运行目录。

**✅ 验收**：窗口最后显示部署完成，且项目根目录出现 `venv\Scripts\python.exe`。

**⛔ 卡住了**
- 提示"未检测到 Python" → 按提示装 64 位 Python 3.12（安装时勾选 **Add Python to PATH**），
  装完**重开**窗口再跑一次
- 提示"检测到的是 32 位 Python" → 必须是 64 位，否则多个二进制依赖装不上

**⛔ 卡住了**
- 提示"未找到 Python" → 确认安装时勾选了 **Add Python to PATH**，然后重开窗口
- 依赖安装失败 → 看窗口里的红色报错；联网环境可重跑一次；内网环境请确认 `offline_packages/` 已通过 `git lfs pull` 拉全
- 任何情况都可以跑一次自检看结论：双击 **`诊断.bat`**

## 三、填写配置（两项必填）

### 最简单的方式：让启动脚本引导你

直接双击 **`启动幻帧.bat`**：

- 如果还没有 `.env`，它会**自动从模板生成**（并写入一个随机 JWT 密钥），
  然后弹出提示并**打开记事本**，让你填写两项必填配置；
- 填完保存、关闭记事本，**再双击一次** `启动幻帧.bat` 即可。

### 手动方式

在项目根目录复制模板：

```powershell
copy .env.example .env
copy config.example.yaml config.yaml
```

用记事本打开 **`.env`**，**至少改这两项**：

```env
# 1) 管理员密码（首次启动会用它创建管理员账号）
HUANZHEN_ADMIN_PASSWORD=换成你自己的强密码

# 2) 至少一个模型密钥（默认用 DeepSeek）
DEEPSEEK_API_KEY=sk-你的密钥
```

其余项可留空——**留空只会让对应功能不可用，不会导致服务起不来**。

**✅ 验收**：`.env` 里 `HUANZHEN_ADMIN_PASSWORD` 已改为你自己的密码、且至少有一个 `*_API_KEY` 有值。

**⛔ 卡住了**
- 该用哪个模型的密钥？默认 `config.yaml` 里 `models.default: deepseek`，
  可换成 `zhipu`（智谱）等；国内直连的不需要代理。
- 想用本地模型不外传数据？见 [故障排查 · 想用本地模型](故障排查.md)
- `诊断.bat` 会直接告诉你"哪个密钥没配"

## 四、启动服务

双击 **`启动幻帧.bat`**。

它的行为：

```
[1/3] 后台启动服务（无窗口，关闭本窗口不影响服务）
[2/3] 轮询等待服务就绪（首次启动 10~40 秒，要连接 MCP 服务）
[3/3] 就绪后自动打开浏览器
```

> 服务以**无窗口**方式后台运行，这是刻意的：避免误关窗口把服务带下去。
> 想看日志就用 **`运行服务.bat`**（带黑窗，日志直接打印）。

**✅ 验收**：窗口出现「服务已就绪 → http://127.0.0.1:8000/」，且浏览器自动打开。

**⛔ 卡住了**
- 提示 120 秒未就绪 → 看 `logs\launcher.err.log`，或双击 `诊断.bat`
- 浏览器白屏 → 手动访问 <http://127.0.0.1:8000/health>，
  期望看到 `{"status":"healthy",...}`

## 五、验证（三步，别跳过）

### 5.1 环境自检

双击 **`诊断.bat`**，期望结尾是：

```
结果：无阻断问题，N 个警告（不影响启动）
可以启动：双击 launch_huanzhen.bat
```

- 有 **ERROR**（✗）就必须先按它给的「→ 修复建议」处理
- 有 **警告**（!）通常是可选能力（Node/Ollama/可选依赖），不影响基本使用

### 5.2 登录

浏览器打开 <http://127.0.0.1:8000/>

- 用户名：`admin`（见 `config.yaml` 的 `security.bootstrap_admin.username`）
- 密码：你在 `.env` 里设的 `HUANZHEN_ADMIN_PASSWORD`

### 5.3 发一条测试消息

在对话框输入：

```
你好，请自我介绍并列出你能做的事
```

**✅ 验收**：能流式返回回答；回复里能看到工具/模型正常工作。

**⛔ 卡住了**
- 登录提示密码错误 → 若你之前已初始化过，改 `.env` 不会改已有账号密码，
  请用 `venv\Scripts\python.exe scripts\reset_password.py` 重置
- 消息一直转圈 / 报密钥错误 → 回到第 3 步确认模型密钥；`诊断.bat` 会指出问题

## 六、让局域网内其他电脑也能用（可选）

服务默认监听 `0.0.0.0:8000`，同一内网的其他电脑访问即可：

```
http://<这台电脑的内网IP>:8000/
```

查本机内网 IP：

```powershell
ipconfig | Select-String "IPv4"
```

**放行防火墙**（管理员 PowerShell，只需一次）：

```powershell
New-NetFirewallRule -DisplayName "幻帧 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow
```

**⛔ 卡住了**
- 别人打不开 → ① 确认用的是内网 IP 不是 `localhost`；② 确认防火墙已放行；
  ③ 确认两台机器在同一网段

## 七、日常操作速查

| 我要做什么 | 怎么做 |
|---|---|
| **启动** | 双击 `启动幻帧.bat`（后台）或 `运行服务.bat`（看日志） |
| **停止** | 双击 **`停止服务.bat`**（也可在 `运行服务.bat` 窗口按 `Ctrl+C`） |
| **备份数据** | 双击 **`备份.bat`**（服务启动时也会**每天自动备份一次**） |
| **自检** | ① 网页「设置 → 系统状态 → 运行环境自检」；② 服务起不来时双击 `诊断.bat`（自动修复缺失配置用 `诊断.bat --fix`） |
| **更新代码** | `git pull` → 若 `requirements.txt` 有变化，重跑一次 `setup_deploy.bat` → 重启服务 |
| **看日志** | `logs\agent.log`（主日志，超过 10MB 自动轮转）、`logs\audit.jsonl`（审计） |
| **改配置** | 改 `.env` / `config.yaml` 后**必须重启服务** |
| **重置管理员密码** | `venv\Scripts\python.exe scripts\reset_password.py` |

## 八、目录速查（哪些能动、哪些别删）

| 路径 | 说明 | 能删吗 |
|---|---|---|
| `venv/` | Python 虚拟环境 | 可删，但需重跑 `setup_deploy.bat` |
| `.env` / `config.yaml` | **你的私密配置，已被 gitignore** | ❌ 删了要重新配 |
| `data/` | 数据库、向量库、团队文件工作区 | ❌ **删了对话与知识库全没** |
| `data/backups/` | 自动/手动备份（zip，默认留 7 份） | ⚠️ 可清理旧的，但至少留一份 |
| `data/security/jwt_secret` | JWT 签名密钥 | ❌ 删了所有人掉线 |
| `sessions/` | 会话记录 | ⚠️ 删了丢历史上下文 |
| `logs/` | 日志与审计 | ✅ 可定期清理 |
| `offline_packages/` | 离线依赖包 | ⚠️ 删了以后只能联网部署 |
| `web/dist/` | 前端构建产物（随仓库分发） | ❌ 删了页面打不开 |

**迁移到另一台机器**：整目录拷贝即可，但**必须带上** `.env`、`config.yaml`、`data/`。

## 九、卸载

1. 双击 `停止服务.bat`
2. 删除整个项目目录
3. （可选）清理残留：`%USERPROFILE%\.huanzhen`（若存在）

## 十、还是不行？

按顺序做这三件事，90% 的问题能自己解决：

1. **双击 `诊断.bat`** —— 它会指出具体是哪一项不满足，并给出修复命令
2. **看 [`故障排查.md`](故障排查.md)** —— 按症状查（启动 / 登录 / 模型 / 知识库 / 桌面自动化 / 数据安全）
3. **需要求助时**，按故障排查手册最后一节准备信息（自检报告 + 日志末尾 + 版本），
   ⚠️ 提交前请确认内容里**没有 API Key**
